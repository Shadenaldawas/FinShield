# PDPL — Paraphrased Summary (NOT legal text — see sources_log.md for official links)

Saudi Arabia's Personal Data Protection Law governs how any entity processing the
personal data of individuals inside the Kingdom must handle that data — including
foreign entities processing KSA residents' data remotely. SDAIA is the supervising
authority. Core themes relevant to a digital financial product: data subjects must
generally consent to processing, entities must register as controllers, breaches
must be reported to the regulator within a short window, and cross-border data
transfer is restricted unless specific safeguards are met.

**topics:** data_privacy, pdpl, cross_border_data, consent
