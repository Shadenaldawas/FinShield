# Domain data — SYNTHETIC / DEMO ONLY

Everything in this folder is fabricated for demo purposes. None of it represents
a real financial institution or real market data. It exists so the prototype has
realistic-looking inputs to score without requiring live data feeds (which are
out of scope for a hackathon prototype per the brief).

- `demo_institutions.json` — sample institution profiles, incl. the brief's demo
  scenario ("digital investment product" launch).
- `market_indicators.json` — a handful of illustrative macro figures per target
  market, used only as light context in the report — not in the score itself,
  to avoid implying we have real macroeconomic data pipelines.
